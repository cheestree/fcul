\section{Contributions}\label{sec:research-goals}

This work makes two related contributions. 
First, it provides an integrated authorisation data resource that maps heterogeneous records from the European Union, Spain, France, and Portugal to a shared schema. 
The resource keeps crop, pathogen, product, microbial active substance, authorisation, source, and review information where these fields are available. 
It also preserves unresolved and discarded records as explicit output classes rather than presenting incomplete source data as verified crop--pathogen associations. 
Only the Portuguese records currently provide the complete fields required by the ranking evaluation; the remaining sources support catalogue inspection and data integration but are not treated as complete use-level evidence.

Second, it provides a transparent ranking framework for microbial BCAs identified through commercial authorisation records. 
The framework combines direct support for the queried crop--pathogen context with pathogen-level support and a small collaborative similarity signal. 
It ranks canonical microbial active-substance values while retaining commercial products as traceable supporting evidence. 
The evaluation tests whether this framework retrieves held-out authorisation associations in warm-start contexts.

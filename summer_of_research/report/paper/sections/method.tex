\section{Method}\label{sec:methodology-or-approach}

The method has three stages.
First, the data stage integrates heterogeneous authorisation sources into a shared schema.
Second, the database stage identifies BCA-related records and constructs an authorisation-based commercial BCA resource with explicit evidence and review states. 
Third, the recommender stage uses the accepted records to rank microbial BCA candidates for crop--pathogen queries. 
The stages are evaluated separately so that data processing, database construction, and candidate retrieval are not treated as the same task.
